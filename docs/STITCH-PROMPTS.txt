GHURIFY - GOOGLE STITCH PROMPTS
Airbnb-style redesign, one prompt per screen. Plain text, ready to paste.

HOW TO USE
1. Create one Stitch project for web. Paste the STYLE prompt first, on its own.
2. Then paste one screen prompt at a time, in order. Each one starts with
   "Same Ghurify style" so Stitch keeps the theme. If a result drifts, paste the
   STYLE prompt again together with the screen prompt.
3. For the mobile version, create a second Stitch project set to mobile, paste the
   STYLE prompt, then the same screen prompts. Each prompt ends with a MOBILE line that
   says what changes on a phone.
4. All sample content below matches the fields the Ghurify API really returns. Do not
   let Stitch add photos, star ratings on trip cards, wishlist hearts or profile photos:
   the app has no data for them.
5. To get a Bangla version of a screen, after it is generated ask Stitch:
   "Translate all interface text on this screen to Bangla, keep the layout."

STYLE PROMPT (paste first)
==================================================================================

Design system for "Ghurify", a web app for joining group trips around Bangladesh with
verified hosts, escrow payments and an SOS button on every trip. Use Airbnb's design
language as the reference: a quiet white canvas, near-black text, thin grey divider
lines between sections instead of boxed cards, large media tiles with 12px rounded
corners, generous whitespace, and only one strong coloured button per screen. Do not use
Airbnb's logo, red colour or name.

Colours: background white #FFFFFF; main text #222222; secondary text #6A6A6A; divider
lines #DDDDDD; light grey surfaces #F7F7F7. Brand button: a horizontal gradient of
jamdani pink-maroon from #8C2650 to #A3305C to #B8486F with white text. Dark button:
#222222 with white text. Trust colour (verified badges, success, logo): forest green
#245C43. Highlight colour (few seats left, new requests): turmeric #D99A12. Error and
emergency red: #C13515. Warning: amber. Status chips for destinations: green "Open",
amber "Caution", red "Closed".

Typography: Hind Siliguri for all text (it supports Bangla and English). Titles semibold,
body regular 16px. Headline sizes: page title 32px, section title 22px. The logo
wordmark "Ghurify" uses Baloo Da 2 bold in forest green.

Shapes: buttons 8px radius, 48px tall; cards and media tiles 12px radius; pills fully
rounded; avatars are circles showing the person's initial on a soft coloured background
(there are no profile photos). Shadows are soft and rare: only on the search pill, the
sticky booking card and pop-up menus.

Images: there are NO photographs in this product. Every place where Airbnb would show a
photo shows a flat, layered vector landscape illustration in soft natural colours that
matches the destination type: hills, beach, island, forest, wetland, tea garden, lake
or river.

Icons: simple outline icons, 2px stroke, rounded ends. Currency is Bangladeshi taka,
written like "৳8,500". Language toggle shows "EN | বাং". Tone: warm, calm, trustworthy,
sentence case everywhere.

Global header (on every screen, white, 80px, thin bottom divider): "Ghurify" logo on the
left; in the centre a rounded search pill reading "Anywhere | Any dates | Add travellers"
with a round brand-gradient search button; on the right a "Lead a trip" text link, a
globe icon, a bell icon, and a rounded user-menu pill with a hamburger icon and an avatar.

Footer (light grey #F7F7F7): three link columns - Explore (Trips, Destinations,
Stories), Safety (How SOS works, Women-only trips, Emergency 999), Hosting (Lead a trip,
Hosting dashboard); bottom row with "© 2026 Ghurify", the language button, and a small
green dot with "All systems normal".
